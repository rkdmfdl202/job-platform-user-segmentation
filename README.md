# 채용 플랫폼 사용자 행동 기반 세그먼테이션 분석

> **공고는 봤는데, 왜 지원하지 않았을까?**  
> 팀 프로젝트에서 담당한 **사용자 세그먼테이션(RJA) 분석**만 별도로 정리한 코드 저장소입니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 분석 대상 | 2023년 채용 플랫폼 사용자 활동 로그 및 지원 데이터 |
| 담당 범위 | 사용자별 최근 활동·공고 조회·지원 횟수 집계, 점수화 및 그룹 분류 |
| 분석 방식 | **RJA 규칙 기반 세그먼테이션** (R: Recency, J: Job view, A: Application) |
| 사용 도구 | Python, Pandas, NumPy, Matplotlib, Jupyter Notebook |
| 주요 목적 | **탐색은 활발하지만 지원 횟수는 낮은 사용자 그룹 식별** |

## 분석 과정

1. 활동 로그 사용자와 지원 기록을 사용자 ID 기준으로 연결해 행동 지표를 산출했습니다.
2. **R(최근 활동일 경과), J(채용공고 상세 조회 횟수), A(지원 횟수)** 를 각각 1~4점으로 점수화했습니다.
3. 원본 팀 노트북의 분류 조건에 따라 **핵심 / 적극 탐색 / 이탈 위험 / 휴면 구직자** 4개 그룹으로 분류했습니다.
4. 그룹별 규모와 평균 최근성·조회 횟수·지원 횟수를 비교했습니다.

## 주요 결과

원본 팀 프로젝트 노트북에 **기록된 실행 결과**입니다. 이 저장소의 축약 노트북은 원본 CSV가 포함되지 않아 별도로 재실행한 결과가 아닙니다.

| 세그먼트 | 사용자 수 | 평균 최근활동 경과일 | 평균 공고 상세 조회 | 평균 지원 횟수 |
| --- | ---: | ---: | ---: | ---: |
| 핵심 구직자 | **2,260명** | 36일 | 109회 | 15회 |
| 적극 탐색 구직자 | **2,507명** | 39일 | 60회 | 1회 |
| 이탈 위험 구직자 | **3,848명** | 134일 | 24회 | 2회 |
| 휴면 구직자 | **6,751명** | 209일 | 5회 | 1회 |
| **합계** | **15,366명** | | | |

원본 노트북 기준 **지원 경험 사용자 비율은 약 37.21%**였습니다. 이는 분석 로그에 등장하는 고유 사용자 중 지원 기록이 있는 사용자의 비율이며, 공고 조회 건수 대비 지원 전환율은 아닙니다.

### 핵심 인사이트

**적극 탐색 구직자**는 평균 공고 상세 조회가 60회로 높은 반면 평균 지원 횟수는 1회로 나타나, 탐색과 지원 행동의 차이를 추가로 살펴볼 후보군으로 확인했습니다. **지원하지 않는 실제 원인을 확인한 것은 아니며**, 개인화 채용공고 추천 등은 후속 검증이 필요한 가설입니다.

## 점수 및 분류 기준

| 기준 | 1점 | 2점 | 3점 | 4점 |
| --- | --- | --- | --- | --- |
| R: 최근활동 경과일 | 241~365일 | 119~240일 | 60~118일 | 0~59일 |
| J: 공고 상세 조회 | 0회 | 1~6회 | 7~31회 | 32회 이상 |
| A: 지원 횟수 | 0회 | 1~2회 | 3~8회 | 9회 이상 |

- **핵심:** R≥3, J≥3, A≥3
- **적극 탐색:** R≥3, J≥3, A<3
- **이탈 위험:** 위 두 그룹이 아니면서 R≥2, J≥2
- **휴면:** 나머지

'이탈 위험'과 '휴면'은 **원본의 규칙 기반 세그먼트 명칭**으로, 이탈을 통계적으로 예측한 결과는 아닙니다.

### 데이터 안내

실행에는 팀 프로젝트에서 사용한 `applicaion_2023.csv`, `log2023_df_url.csv`가 필요합니다. 원본 파일명 `applicaion`은 원본 노트북 표기를 유지했습니다. **원본 CSV와 개인 사용자 식별자는 저장소에 업로드하지 않습니다.** 두 CSV를 노트북과 같은 폴더에 저장한 뒤 순서대로 실행할 수 있습니다.

## 분석 한계

- 임의로 정한 점수 경계와 그룹 기준을 바꾸면 결과가 달라질 수 있습니다.
- 조회 로그는 지원 의도를 직접 측정하지 않으며, 저지원 원인을 식별할 수 없습니다.
- 사용자 이탈이나 개인화 추천 효과는 본 분석에서 검증하지 않았습니다.
